# 家族アプリ

ルーチン・ありがとうポイント・スクリーンタイムを家族で共有する PWA（スマホのホーム画面に追加して使う Web アプリ）。

- `config.js` に Firebase の設定が入っていれば、家族の端末どうしで同期します
- `null` のままなら「お試しモード」（その端末だけに保存）で動きます
- 家族の名前などはすべて Firestore 側に保存され、コードには入りません

## ファイル
| ファイル | 内容 |
|---|---|
| index.html | アプリ本体 |
| config.js | Firebase の設定（公開して問題ない値） |
| firestore.rules | Firestore のセキュリティルール（家族の端末だけが読み書きできる） |
| sw.js / manifest.webmanifest / icon-*.png | PWA 用 |

## しくみ
- 各端末は Firebase の匿名ログインで識別します
- 最初の端末で「新しく家族をつくる」→ 8けたの家族コードが発行されます
- ほかの端末は「家族コードで参加」で同じ家族につながります
- 開始・終了の時刻はサーバー時刻で補正されるので、端末の時計をずらしても影響しません
- 親の PIN はハッシュ化して保存します
